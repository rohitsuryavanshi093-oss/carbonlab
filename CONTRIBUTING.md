Contributing to CarbonLab

Thank you for your interest in CarbonLab.

CarbonLab is an open, research-oriented computational project focused on investigating carbon-dioxide-removal pathways using transparent data, quantitative modeling, uncertainty analysis, and scenario exploration.

The project is still in early development, so the structure and contribution guidelines may change as the research develops.

Before contributing

Please understand the project's main principles:

- Scientific accuracy comes before adding features.
- Sources should be traceable whenever possible.
- Assumptions should be documented.
- Results should be reproducible.
- Uncertainty should not be hidden.
- Research conclusions should not be predetermined.
- AI-generated information should not be treated as automatically correct.

Types of contributions

Useful contributions may include:

- identifying relevant scientific literature
- suggesting reliable public datasets
- improving data provenance
- identifying errors in calculations
- improving documentation
- improving tests
- finding bugs
- suggesting improvements to computational methods
- reviewing assumptions
- proposing well-defined research questions

Scientific contributions

For contributions involving scientific data or claims, please provide the source whenever possible.

For quantitative values, useful metadata may include:

- source
- publication
- parameter name
- value
- units
- geographical context
- time period
- assumptions
- uncertainty
- methodological notes

Please do not add unsupported numbers simply because they seem reasonable.

Code contributions

Code should be:

- readable
- reasonably modular
- tested where practical
- documented when the reasoning is not obvious
- reproducible where possible

Avoid adding unnecessary complexity.

A smaller implementation that can be understood and tested is generally preferable to a complicated implementation that is difficult to verify.

Research integrity

Contributors must not intentionally add:

- fabricated data
- fabricated citations
- fabricated experimental results
- misleading claims
- copied research presented as original work
- credentials or achievements that are not true

If a result is uncertain or a limitation is discovered, it should be documented rather than hidden.

Pull requests

When proposing a substantial change, please explain:

1. What was changed?
2. Why was it needed?
3. What assumptions were introduced?
4. What sources or evidence support the change?
5. How was the change tested?
6. Could the change affect existing results?

For research-related changes, include enough information for another person to understand and reproduce the reasoning.

Issues

Issues can be used to report:

- bugs
- incorrect calculations
- questionable assumptions
- data problems
- documentation problems
- reproducibility problems
- potential research questions

Please provide enough context to reproduce a technical problem whenever possible.

Development status

CarbonLab is currently a developing research project.

The architecture, datasets, models, and research questions may change as evidence is reviewed and experiments are performed.

Not every proposed feature will necessarily be accepted.

Research value and reproducibility will be prioritized over simply increasing the number of features.

Code of conduct

Please communicate respectfully and focus criticism on the work, methods, assumptions, or evidence rather than on individuals.

---

These guidelines may be updated as CarbonLab develops.
